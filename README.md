# Nook & Ink

**Versión 1.1 · Desarrollo de las primeras pantallas con Jetpack Compose**

---

### Sobre el proyecto

Nook & Ink continúa su desarrollo pasando de la fase de diseño y prototipado a la creación de la aplicación. En esta versión se implementan las dos primeras pantallas utilizando Jetpack Compose: una estantería con libros de ejemplo y una pantalla de detalle con la información de cada libro.

### Esta versión incluye

- Creación de la pantalla principal de estantería.
- Pantalla de detalle de cada libro.
- Conexión entre ambas pantallas mediante la gestión del estado en Compose.
- Datos de ejemplo para mostrar los libros.
- Adaptación de las pantallas a la orientación del dispositivo.
- Estructura inicial preparada para futuras funcionalidades.
